🍅 PomoZone

A Pomodoro timer with a visual statistics dashboard. Three screens, one Room table, no gamification. This is what the finished app will look like and do.

Screens

Features

TIMER

Pomodoro cycle

The core loop.

  • Focus 25 min, short break 5, long break 15 after every 4th focus
  • Start, pause, resume, reset, skip
  • Animated progress ring and session dots
  • Stays accurate when the app is backgrounded
STATS

Visual dashboard

Everything is drawn from one list of sessions.

  • Today, week, and all-time focus totals
  • Daily goal ring (sessions today)
  • Weekly bar chart that animates in
  • GitHub-style heatmap of 12 weeks
  • Streak counter
ALERTS

Completion notice

So you can leave the screen.

  • Notification when a session ends
  • Vibration
  • Only finished focus blocks are logged
POLISH

Look and feel

Cheap touches that read well in a README GIF.

  • Light and dark theme
  • Focus is red, breaks are green and blue
  • Empty state for a first launch
  • Demo data in debug builds for screenshots
NOT IN SCOPE

Left out on purpose

Listed in the README as “what I’d add next”.

  • XP, levels, badges
  • Settings screen for custom durations
  • Foreground service
  • Cloud sync or accounts
